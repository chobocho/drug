# 💊 약 체크

`index.html`을 브라우저에서 열어 사용합니다. 인터넷 연결이나 서버는 필요하지 않습니다. 브라우저가 `file://`에서 IndexedDB를 차단하면 이 폴더에서 `python -m http.server`를 실행한 뒤 표시된 로컬 주소로 접속하세요.

- 아침약, 저녁약, 안약을 체크하고 설정에서 점심약을 켜거나 다른 약을 추가합니다.
- 약마다 복용 요일을 설정할 수 있습니다. 설정 변경은 오늘부터 적용됩니다.
- 기록은 브라우저에 저장되며 최근 3개월치만 유지합니다. 브라우저 데이터 삭제 시 기록도 사라질 수 있습니다.
- 설정에서 JSON 백업을 저장하고 복원할 수 있습니다. 복원하면 현재 데이터가 대체됩니다. 백업에는 복약 정보가 평문으로 들어 있습니다.

## 개발

Node.js 설치 후 `npm install`을 실행합니다.

- `npm run build`: TypeScript를 컴파일하고 CSS와 JavaScript가 포함된 단일 `index.html` 생성
- `npm test`: 빌드 후 자동 테스트 실행

자세한 동작은 [DESIGN.md](DESIGN.md)를 참고하세요.
